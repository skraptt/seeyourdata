# Privacy policy

SeeYourData does not collect, store, sell or send any of your data.

- **No network requests.** The extension never contacts a server. It has no analytics, crash reporting, remote configuration or accounts.
- **Local only.** What it observes about the pages you visit (which servers they contact, which browser features they use, which kinds of form fields they have) is kept in your browser's session memory, per tab. It is deleted when you close the tab or the browser.
- **No form contents.** The extension counts the *types* of form fields on a page (for example "an email field"). It never reads what you type.
- **Reporting is opt-in.** The popup's "Report" and "Suggest a correction" links open a GitHub issue form in a new tab, pre-filled with the server's domain and the website's domain (never the full page address). Nothing is sent unless you submit that form on GitHub yourself.
- **No changes to pages.** It observes requests and browser features without blocking or altering them.

The source code is public, so you can check all of this yourself.
